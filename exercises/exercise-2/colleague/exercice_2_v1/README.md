## Points à valider côté client, sans bloquer la revue du format
1. La colonne `Salaries` de `Q1` est vide dans le classeur de départ ; les salaires présents dans `SOL` sont utilisés dans la solution client, mais leur reprise comme données de démonstration doit être confirmée.
2. La question 5 de la correction omet le critère `Salaires > 4000` ; la formule du script suit le texte de l'énoncé.
3. La question 7 de la correction omet le critère `Salaires <= 4000` ; la formule du script suit le texte de l'énoncé.
4. L'énoncé écrit `Upper Classes`, alors que la solution utilise `Upper Class`.
5. Les formules de la vidéo 2 sont reproduites selon les noms de plages du classeur solution. Vérifier les noms localisés/importés au moment de la génération automatique du classeur de tournage.

Le pack ne contient volontairement que les vidéos 00 à 02, comme demandé pour valider le format avant de rédiger les vidéos suivantes.
